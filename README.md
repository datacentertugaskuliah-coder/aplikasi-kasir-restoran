# Aplikasi Kasir Restoran

Web-based POS (Point of Sale) untuk restoran single-outlet, dioptimasi untuk tablet.

## Struktur Project
- `backend/` — REST API (Node.js + Express)
- `frontend/` — Web app (React + Vite)
- `docs/` — Dokumentasi (PRD, task list)

## Stack
- Backend: Node.js, Express, PostgreSQL (dev: SQLite)
- Frontend: React (Vite)
- Auth: JWT role-based (Kasir, Pelayan, Owner)
